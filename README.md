# LloyDOS
A project written to learn about writing C/ASM from scratch to bootstrap into a more functional environment. The goal ultimately will be to have a version for RISCV/Xtensa compatibility, but for now x86 is the choice of platform because it's the most commonly written in for this sort of thing. Mostly meant to accelerate my understanding of OS for my esp32-kernix project (right now it's basically just an application-level system with malloc()/CSTDLIB built-in from esp-idf).
